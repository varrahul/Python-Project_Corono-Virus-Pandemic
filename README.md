Corona Virus Pandemic Dashboard is an interactive data visualization application built using Python, Dash, Plotly, and Pandas. The dashboard analyzes COVID-19 data from a state-wise dataset and presents key statistics such as total cases, active cases, recoveries, and deaths through dynamic cards and charts. Users can interact with dropdown menus to explore different metrics using bar charts, line graphs, and pie charts, providing an intuitive way to understand pandemic trends and state-wise distributions.
